# 本地有媒体，QQ 却提示过期？

这不一定表示文件消失：旧文件卡片引用可能异常；原件路径可能断开；视频原片虽在，缺少封面缓存也会让聊天卡片显示过期。三种原因对应不同处理：按已验证规则修正卡片记录、核验本地原件后补回缺失路径、从本地视频生成派生首帧封面。它们不是通用的一键恢复。

建议先退出 QQ，只读清点并核对记录与原件字节，审阅 dry-run，授权后处理，再回原聊天抽查。没有原片不能凭空恢复；索引未命中不等于永久丢失；未知错误标记不要擅自清除。派生封面不是云端原图，路径数也不代表照片数。

公开分享请保护账号、密钥、聊天内容和本地文件信息。项目：[qqnt-media-repair](https://github.com/BRsjtu/qqnt-media-repair)。
